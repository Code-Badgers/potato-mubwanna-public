# 기능 명세서

## 1. 회원 / 인증

| 기능 ID  | 기능명         | 설명                                              | 우선순위 |
| -------- | -------------- | ------------------------------------------------- | -------- |

| AUTH-005 | 위치 권한 안내 | GPS 인증을 위해 위치 권한 필요성을 안내한다.      | High     |
