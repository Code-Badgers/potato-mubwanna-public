# 감자 성장 정책

## 1. 목적

감자밭은 단순 수집 화면이 아니라, 사용자가 강원도 여행과 일상 걸음을 이어가며 대표 감자를 키우고 직접 수확하는 게임형 성장 루프를 담당한다.

성장 정책은 다음 목표를 기준으로 설계한다.

- 사용자가 매일 앱을 다시 열 이유를 만든다.
- 걸음 수와 감자 상호작용이 모두 성장에 기여하도록 한다.
- 희귀도가 높은 감자일수록 더 오래 키울 수 있게 하되, MVP 단계에서는 과도한 복잡도를 피한다.
- 쓰다듬기, 물주기, 영양제 주기는 무제한 클릭 보상이 아니라 쿨타임이 있는 짧은 돌봄 행동으로 둔다.
- 성장 완료와 획득을 분리해, 사용자가 `감자 수확하기`를 눌렀을 때 도감 카드 획득 감정을 느끼게 한다.

## 2. 희귀도별 최대 레벨

기본 감자는 가장 빨리 완성되는 입문 감자로 두고, 희귀도에 따라 최대 성장 레벨을 차등 적용한다.

| 희귀도 | 최대 레벨 | 의도 |
| --- | ---: | --- |
| COMMON | 3 | 첫 감자와 기본 감자. 빠르게 성장 완료 경험을 준다. |
| RARE | 5 | 지역별 대표 감자. 짧은 여행 기간 동안 완성 가능하다. |
| EPIC | 8 | 특별 장소, 미션, 혼잡도 보상 감자. 반복 방문 동기를 만든다. |
| LEGENDARY | 10 | 장기 수집 목표. 완성 자체가 주요 성취가 된다. |

## 3. 성장 경험치 기준

현재 백엔드의 `growthDistance`는 거리 기반 성장 경험치로 사용한다.

- 걸음 수 동기화: HealthKit 또는 Health Connect의 양의 이동 거리 증가분만 성장에 반영한다.
- 상호작용: 액션별 고정 성장 거리 보너스를 지급한다.
- 최대 레벨에 도달한 감자는 진행률을 100%로 고정하고 추가 성장 보상은 반영하지 않는다.

프론트 UI에서는 내부 수치를 모두 노출하지 않고 `수확까지 N%`로 단순화한다. 단계 표시는 다음 4단계로 고정한다.

| 단계 | 표시명 | 이미지 정책 |
| --- | --- | --- |
| 1 | 아기 감자 | 공통 성장 이미지 |
| 2 | 어린 감자 | 공통 성장 이미지 |
| 3 | 통통 감자 | 공통 성장 이미지 |
| 4 | 최종 감자 | 해당 감자의 고유 캐릭터 이미지 |

1~3단계는 같은 감자가 점점 자라는 느낌을 주고, 4단계에서 강릉 감자, 평창 감자처럼 지역/종류별 최종 캐릭터가 등장한다.

## 4. 상호작용 액션 정책

| 액션 | 성장 보너스 | 쿨타임 | UI 의도 |
| --- | ---: | ---: | --- |
| 쓰다듬기 | 50m | 30분 | 가장 가벼운 애정 표현. 자주 눌러도 과보상되지 않는다. |
| 물주기 | 120m | 2시간 | 감자 컨디션을 챙기는 중간 보상. |
| 영양제 주기 | 200m | 4시간 | 보상감이 있지만 하루 반복 횟수를 제한한다. |

산책 보상은 백엔드 액션으로는 유지하되, 감자밭 메인 UI에서는 세 버튼을 한 줄로 유지하기 위해 노출하지 않는다. 실제 이동 성장은 오늘 감자걸음과 HealthKit/Health Connect 동기화 흐름으로 표현한다.

## 5. 획득 방식

감자는 모두 같은 방식으로 얻지 않는다. 데이터 기준으로 획득 방식을 구분한다.

| 획득 방식 | 설명 |
| --- | --- |
| `growth` | 감자밭에서 4단계까지 성장 후 수확 |
| `mission` | 미션 완료 시 즉시 획득 |
| `visit` | 특정 장소 방문 인증 시 즉시 획득 |
| `stamp` | 특정 스탬프 획득 시 즉시 획득 |
| `event` | 시즌/이벤트 조건 완료 시 즉시 획득 |

성장형 감자는 `성장 완료 → 감자 수확하기 → 카드/캐릭터 획득` 흐름을 따른다. 즉시 획득형 감자는 조건 충족 시 도감 카드와 캐릭터를 바로 획득한다.

## 6. 수확 UX

수확 상태는 다음처럼 표현한다.

| 상태 | CTA |
| --- | --- |
| 성장 중 | 아직 자라고 있어요 |
| 수확 가능 | 감자 수확하기 |
| 수확 완료 | 획득한 감자 보기 |

`감자 수확하기`를 누르면 약 60% 검은 반투명 배경 위에 획득 카드가 뜨고, `새로운 감자를 수확했습니다` 메시지를 보여준다.

## 7. 영속화 기준

감자 상호작용은 `user_potato_interactions`에 기록한다.

- 사용자 감자와 액션, 성장 보너스, 실행 시각을 저장한다.
- 같은 감자와 같은 액션의 마지막 실행 시각을 기준으로 쿨타임을 계산한다.
- 쿨타임 중 재시도하면 성장 수치를 변경하지 않고 거절한다.
- 대표 감자가 없거나 이미 최대 레벨이면 상호작용은 실패 응답으로 처리한다.

현재 백엔드는 `UserPotato`가 이미 획득된 감자를 성장시키는 구조다. 수확 전 상태까지 완전히 저장하려면 후속으로 수확 API와 `harvestable`, `harvested`, `acquisitionType` 응답 필드를 공식화해야 한다.

## 8. API 설계

대표 감자 상호작용은 아래 endpoint로 처리한다.

```http
POST /api/potatoes/me/representative/interactions
```

Request:

```json
{
  "action": "PAT"
}
```

Response:

```json
{
  "success": true,
  "data": {
    "potatoId": 1,
    "potatoName": "초보감자",
    "action": "PAT",
    "growthDistanceAdded": 50.0,
    "cooldownSeconds": 1800,
    "nextAvailableAt": "2026-08-16T15:30:00Z",
    "growthResult": {
      "potatoId": 1,
      "potatoName": "초보감자",
      "previousLevel": 2,
      "currentLevel": 3,
      "leveledUp": true,
      "fullyGrown": true
    }
  }
}
```

## 9. 후속 조정 후보

- 감자별 성격에 따라 선호 액션을 다르게 두는 정책
- 특정 지역 스탬프 획득 후 성장 보너스 배율 적용
- 하루 돌봄 완료 보너스
- 수확 API 추가 및 수확 전/후 도감 잠금 상태 영속화
- 수확 완료 시 대표 감자 설정 추천
