# 12. 점순이 보이스 가이드

## 1. 캐릭터 기준

점순이는 김유정의 소설 동백꽃에 등장하는 점순이를 현대적으로 재해석한 여행 안내자다.

- 새침하고 당돌하다.
- 사용자를 은근히 챙기지만 대놓고 다정한 척하지 않는다.
- 호의를 자랑하듯 또는 무심한 척 건넨다.
- 사용자를 살짝 챙기듯 재촉하되 평가하거나 상처 주지 않는다.
- 감자와 강원도 여행에 자부심이 있다.
- 말보다 행동이 먼저인 야무진 안내자처럼 표현한다.

## 2. 말투 원칙

- 친근한 해요체를 기본으로 한다.
- 문장은 최대 두 문장으로 작성한다.
- 말풍선 문구는 가능하면 35자 이내로 작성한다.
- 설명형 문장보다 직접 말을 거는 문장을 사용한다.
- 느낌표는 남발하지 않는다.
- 사투리는 가볍게만 사용하고, 이해하기 어려운 방언은 피한다.
- 원작 문장은 맥락 없이 반복하거나 과도하게 직접 인용하지 않는다.

## 3. 권장 구조

### 새침한 질문

- 오늘은 어디부터 가볼까요?
- 여기는 한번 들러봐도 좋겠어요

### 무심한 권유

- 내가 괜찮은 곳으로 골라뒀어요
- 지금 풍경은 사진으로 남겨도 좋겠어요

### 자랑 섞인 보상 안내

- 이 감자는 여행 기록에 잘 어울리겠어요
- 잘 다녀왔네요 감자 하나 챙겨요

### 부드럽게 재촉한 뒤 격려

- 조금만 더 걸으면 감자가 더 자라요
- 천천히 해도 괜찮아요 거의 다 왔어요

## 4. 상황별 후보

### 첫 진입

- 오늘 가볍게 다녀오기 좋은 곳이에요
- 내가 괜찮은 곳으로 골라뒀어요

### 점순이 특별 미션

- 오늘은 이곳을 먼저 가봐도 좋겠어요
- 천천히 둘러보고 오면 딱 좋아요

### 위치 미션

- 여기까지 왔으니 기록 하나 남겨봐요
- 내가 골라둔 곳이에요 가볍게 들러봐요

### 사진 미션

- 지금 풍경은 사진으로 남겨도 좋겠어요

### 퀴즈 미션

- 강원도 이야기를 짧게 풀어볼까요?

### 걸음 미션

- 천천히 걸으면 감자도 같이 자라요

### 완료

- 오늘도 잘 다녀왔네요 감자 하나 챙겨요
- 좋아요 여행 기록에 남겨둘게요

### 실패

- 아쉽네요 다시 해보면 금방 맞힐 거예요

### 권한 필요

- 권한이 필요해요 설정에서 한번 확인해봐요

### 네트워크 오류

- 연결이 잠깐 끊겼나 봐요 조금 있다 다시 해봐요

## 5. 피해야 할 표현

- 사용자님, 미션을 수행해 주세요처럼 기계적인 안내
- 지나치게 유아적인 말투
- 매 문장마다 흥, 참, 얼른을 반복하는 표현
- 사용자를 바보 취급하거나 능력을 비하하는 표현
- 욕설, 장애 비하, 가족 비하 등 원작의 거친 표현
- 원작 문장을 모든 화면에서 반복하는 방식
- 시스템 오류의 원인을 흐리는 캐릭터 말투

## 6. UI 적용 원칙

- 제목, 버튼, 입력 안내처럼 기능 전달이 중요한 문구는 명확한 표준어를 유지한다.
- 캐릭터 말투는 점순이 말풍선, 미션 소개, 진행 격려, 완료 메시지에 집중한다.
- 버튼 문구는 지도에서 찾아가기, 사진 찍기, 정답 제출하기처럼 행동이 명확해야 한다.
- 오류 메시지는 먼저 정확한 원인을 알리고, 필요하면 점순이의 짧은 반응을 덧붙인다.
- 같은 상황에서도 대사가 반복되지 않도록 상황별로 3개 이상의 후보를 둔다.

## 7. 구현 기준

- Flutter UI의 점순이 대사는 `frontend/lib/features/mission/presentation/mission_jumsooni_dialogue.dart`에서 관리한다.
- 서버에서 내려오는 미션 제목, 설명, 조건 문구는 임의로 캐릭터 말투로 바꾸지 않는다.
- 대사 후보를 무작위로 노출할 경우 테스트가 흔들리지 않도록 미션 id 또는 상태 기반의 안정적인 선택 방식을 사용한다.
