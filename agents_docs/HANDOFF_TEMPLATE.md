# Handoff Template

Codex 작업 종료, 중단, PR 작성 전에 아래 형식으로 상태를 남긴다. Notion 작업 페이지가 있으면 같은 내용을 복사하거나 동기화한다.

```text
## 작업 요약

- 이슈:
- 브랜치:
- 담당 영역:
- 제외 범위:
- 목표:

## 변경 파일

- `path/to/file`: 변경 내용 요약

## 공유 파일 / 계약 변경

- 공유 위험 파일:
- API 계약 변경:
- DB migration:
- 환경 변수:

## 검증

- 실행:
- 결과:
- 실행하지 못한 명령:
- 이유:

## 산출물

- 검증 기록:
- 화면/API 캡처:
- 기타:

## 남은 리스크

-

## 다음 작업

- 이어서 실행할 명령:
- 확인해야 할 파일:
- 조율이 필요한 사람 또는 이슈:
```

## 작성 규칙

- 실패했던 시도도 숨기지 않는다.
- 추측과 확인된 사실을 구분한다.
- 비밀값은 적지 말고, 필요한 환경 변수 이름만 적는다.
- 다음 에이전트가 바로 이어서 실행할 명령은 정확히 적는다.
