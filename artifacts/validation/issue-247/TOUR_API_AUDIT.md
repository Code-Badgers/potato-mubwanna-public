## 이름과 장소 해석

- `정선 5일장`과 `아리랑시장`은 TourAPI에서 `정선 아리랑시장·정선 5일장(2, 7일)` 콘텐츠 ID `132003` 한 곳으로 제공된다. 중복 마커를 만들지 않고 앱 표시명은 기존 미션 호환을 위해 `정선 5일장`으로 유지한다.
- `장릉`은 김포·파주에도 동명이 있으므로 강원특별자치도 영월군 콘텐츠 ID `125794`만 채택했다.
- `비발디파크`는 TourAPI의 `비발디파크 스키장` 콘텐츠 ID `131301` 중심 좌표를 사용하고 앱 표시명은 계절 중립적인 `비발디파크`로 유지한다.
- `통일전망대`는 고성 `통일전망타워` 콘텐츠 ID `128171`을 사용한다.
- `대관령 양떼목장`은 `detailCommon2`의 대표 이미지가 비어 있어 같은 콘텐츠의 `detailImage2` 첫 번째 공식 이미지를 사용한다.

## 변경 전 확인된 문제

- 랠리북 코드에는 30개 이름이 설명 문자열로만 존재했고 실제 위치 데이터가 아니었다.
- 백엔드에는 지정 명소 중 `남이섬`, `정선 5일장`만 seed 되어 있었다.
- 기존 두 장소는 수기 좌표였고 대표 이미지가 `NULL`이었다.

## 검증

- `TouristSpotMigrationTest`: fresh H2/PostgreSQL 호환 DB에서 migration 적용 통과
- 공식 명소 29개, 강원 18개 시군, TourAPI 콘텐츠 ID, 좌표 범위, HTTPS 대표 이미지, 스탬프 활성 상태 검증
- 기존 수기 좌표 교체 확인:
  - 남이섬: `37.7962651, 127.5254892`
  - 정선 5일장: `37.3805311, 128.6647911`
