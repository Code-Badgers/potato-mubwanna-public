# Issue 302 검증 기록

## 작업 범위

- 감자 도감 캐릭터 이미지를 새 자산 구조로 교체했다.
- 사용자가 직접 누끼 처리한 PNG의 알파 채널은 유지하고, 캐릭터가 같은 캔버스 안에서 중앙에 오도록 크기와 위치만 정리했다.
- Flutter 자산 경로를 `assets/characters/potatoes/` 기준으로 변경했다.
- 기존 서버 코드값과 신규 이미지 파일명을 연결하는 매핑을 추가했다.
- 감자 도감 화면은 서버 `imageUrl`보다 로컬 캐릭터 이미지를 우선 표시하도록 수정했다.

## 고민한 점

### 문제

초기에는 자동 배경 제거로 이미지를 다시 처리했지만, 일부 감자 캐릭터의 흰색 하이라이트와 밝은 장식까지 배경으로 오인되어 사라졌다.

### 분석

사용자가 다시 제공한 이미지는 이미 누끼가 처리된 PNG였으므로, 추가 배경 제거를 하면 오히려 원본 디테일이 손상될 가능성이 컸다.

### 조치

이미지의 알파 채널과 픽셀 색상은 보존하고, 캔버스 크기 통일과 중앙 배치만 수행했다.

### 결과

흰색 디테일 손상 없이 도감용 캐릭터 이미지를 일관된 크기로 정리했다.

## 검증

- `dart format`
  - 대상: 감자 도감 자산 매핑, 감자 도감 화면, 감자 도감 테스트
  - 결과: 통과
- `flutter test test/features/potato/potato_asset_test.dart test/features/potato/potato_collection_screen_test.dart`
  - 결과: 통과
  - 감자 코드 매핑, 대표 감자 선택, 보상 전용 코드 표시, 화면 생명주기 재로딩 테스트를 확인했다.

## 산출물

  - 새 감자 캐릭터 이미지가 동일한 캔버스와 중앙 배치로 정리되었는지 확인하기 위한 시트 이미지다.

## 남은 확인

- 실제 iOS/Android 기기에서 감자 도감 화면을 열어 새 캐릭터 이미지가 의도한 크기로 보이는지 시각 확인이 필요하다.
- 백엔드가 신규 음식형/품종형 코드명을 내려주기 시작하면 현재 직접 매핑 경로로 바로 표시되는지 통합 확인이 필요하다.
