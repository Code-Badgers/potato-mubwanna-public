# #182 iOS/Android 방문 인증 전체 루프 QA 체크리스트

## QA 목적

지도에서 감자 스팟을 선택한 뒤 상세 화면으로 이동하고, 위치 기반 방문 인증을 수행한 다음 스탬프/감자 획득 결과와 점순이 미션 진입까지 자연스럽게 이어지는지 실제 기기 기준으로 확인한다.

## 공통 사전 조건

- 백엔드 서버가 실행 중이어야 한다.
- 프론트 앱 실행 시 `API_BASE_URL`, `KAKAO_NATIVE_APP_KEY`, `KAKAO_JAVASCRIPT_KEY`가 설정되어 있어야 한다.
- 테스트 계정은 카카오 로그인이 완료되어 있어야 한다.
- 테스트용 감자 스팟 데이터가 백엔드 DB에 적재되어 있어야 한다.
- 실제 위치 테스트가 어렵다면, iOS Simulator 또는 Android Emulator의 위치 시뮬레이션 기능으로 스팟 좌표 근처를 지정한다.

## 전체 루프

| 단계 | 확인 항목 | 기대 결과 |
| --- | --- | --- |
| 1 | 앱 실행 후 지도 탭 진입 | 지도와 하단 탭이 깨지지 않고 표시된다. |
| 2 | 감자 마커 선택 | 하단 장소 카드가 선택한 장소명/카테고리/혼잡도로 갱신된다. |
| 3 | 장소 카드의 상세보기 선택 | 선택한 스팟의 상세 화면으로 이동한다. |
| 4 | 방문 인증하기 선택 | 현재 위치 권한을 확인하고 인증 요청을 보낸다. |
| 5 | 인증 성공 | 인증 성공 바텀시트가 표시되고 스탬프/감자 획득 상태가 보인다. |
| 6 | 점순이 미션 보기 선택 | 미션 탭으로 이동하고 방문 인증으로 열린 미션 상세가 표시된다. |
| 7 | 다음 장소 추천 선택 | 지도 탭으로 이동하고 추천 장소가 강조된다. |

## 권한 상태별 QA

| 상태 | 재현 방법 | 기대 결과 |
| --- | --- | --- |
| 위치 권한 허용 | 앱 위치 권한 허용 후 인증 | 인증 요청이 정상 진행된다. |
| 위치 권한 거부 | 앱 위치 권한 거부 후 인증 | 위치 권한 안내 문구가 표시된다. |
| 위치 권한 영구 거부 | OS 설정에서 위치 권한 차단 | 앱 설정으로 이동하는 액션이 표시된다. |
| 위치 서비스 꺼짐 | OS 위치 서비스 비활성화 | 위치 설정으로 이동하는 액션이 표시된다. |
| 인증 반경 밖 | 테스트 위치를 스팟에서 멀리 지정 | 백엔드 실패 메시지가 사용자에게 표시된다. |

## iOS 확인 메모

- Simulator: Features 또는 Debug 메뉴에서 Location을 스팟 근처 좌표로 지정한다.
- 실기기: Xcode Signing 설정과 개발자 인증서 신뢰가 완료되어 있어야 한다.
- HealthKit/FCM 관련 권한 팝업이 함께 뜰 수 있으므로 방문 인증 권한 안내와 혼동하지 않는다.

## Android 확인 메모

- Kakao Map 네이티브 SDK 확인은 ARM 계열 실제 기기에서 우선 검증한다.
- Emulator 사용 시 Kakao native library 아키텍처 이슈가 재발할 수 있다.
- Android Settings에서 위치 권한을 `앱 사용 중에만 허용`, `허용 안 함`으로 바꿔가며 확인한다.

## 캡처해야 할 화면

- `ios-map-selected-spot.png`: iOS 지도 마커 선택 후 장소 카드
- `ios-visit-success.png`: iOS 방문 인증 성공 바텀시트
- `ios-visit-mission-entry.png`: iOS 점순이 미션 진입
- `android-map-selected-spot.png`: Android 지도 마커 선택 후 장소 카드
- `android-visit-success.png`: Android 방문 인증 성공 바텀시트
- `android-visit-mission-entry.png`: Android 점순이 미션 진입
- `permission-denied.png`: 위치 권한 거부 또는 영구 거부 안내

## 발견 시 수정 우선순위

1. 방문 인증 버튼이 눌리지 않거나 인증 요청이 나가지 않는 문제
2. 마커 선택 후 장소 카드가 갱신되지 않는 문제
3. 인증 성공 후 결과 바텀시트가 표시되지 않는 문제
4. 점순이 미션 진입 query parameter가 누락되는 문제
5. 권한 실패 메시지가 사용자에게 표시되지 않는 문제
