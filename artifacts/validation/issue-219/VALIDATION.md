# Issue #219 Validation

## 작업 목표

미션 페이지가 기능은 많지만 한 화면에서 너무 복잡하게 느껴지는 문제를 줄이고, 사용자가 “오늘 할 수 있는 미션”을 빠르게 고를 수 있도록 UX를 단순화한다.

## 진행 내용

- 상단 헤더를 “오늘의 미션” 요약 카드로 변경했다.
- 도전 가능한 미션 수와 완료 수를 먼저 보여주도록 정리했다.
- 미션 필터를 둥근 pill 형태로 정리했다.
- 목록 카드를 티켓형 카드처럼 정리해 제목, 장소, 상태, 조건, 보상을 한 흐름으로 읽히게 했다.
- 미션 상세 화면의 대사/조건/보상 카드 3개를 하나의 “미션 카드”로 통합했다.
- 상세 화면 통합 이후 사용하지 않는 이전 카드 위젯을 제거했다.

## PAAR

### Problem

기존 미션 페이지는 상단 설명, 필터, 카드 안의 배지/보상/진행률/조건이 한꺼번에 보여서 게임형 미션이라기보다 관리 화면처럼 느껴질 수 있었다. 상세 화면도 대사, 보상, 조건이 각각 카드로 나뉘어 화면 밀도가 높았다.

### Action

목록에서는 도전 가능 수와 완료 수를 먼저 보여주고, 각 미션 카드는 상태를 우측 상단에 고정했다. 상세 화면에서는 점순이 대사, 도전 조건, 진행률, 보상을 하나의 카드로 묶어 사용자가 아래 완료 버튼까지 자연스럽게 읽도록 구성했다.

### Analysis

점순이는 미션을 주는 NPC 역할이므로 페이지 전체 카테고리나 헤더에서 과하게 드러내기보다 상세 카드 안의 “점순이 한마디”로만 표현하는 편이 자연스럽다고 판단했다. 또한 기존 검증 로직과 API 호출 흐름은 안정적으로 유지하고, 이번 이슈에서는 화면 구조와 정보 밀도만 줄이는 쪽으로 범위를 제한했다.

### Result

미션 목록은 “오늘의 미션 → 필터 → 티켓형 미션 카드” 흐름으로 정리되었고, 상세 화면은 하나의 게임형 미션 카드로 압축되었다. 기존 퀴즈, 사진, QR, 걸음 인증 테스트는 유지되며 모두 통과했다.

## 남은 리스크

- 실제 iOS/Android 기기에서 카드 높이와 스크롤 체감은 별도 화면 캡처로 확인할 필요가 있다.
- 점순이 또는 미션 타입별 전용 일러스트가 추가되면 카드 상단 아이콘 영역을 이미지 슬롯으로 확장할 수 있다.
