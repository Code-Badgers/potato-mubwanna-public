# 오디오 가이드 점검

## 확인 범위

- 기준 API: `https://potato-mubwanna.duckdns.org/api`
- 확인일: 2026-08-29
- 대상: 운영 관광지 목록 89개와 `GET /audio-guides/spots/{spotId}`

## 결과

- 오디오 응답 200: 12개
- 오디오 미제공 404: 77개
- 기타 오류: 0개

오디오가 확인된 관광지는 남이섬, 소양강 스카이워크, 안목해변, 논골담길, 속초관광수산시장, 환선굴, 횡성호수길, 청령포, 고석정, 화진포, 낙산사, 칠성조선소다.

정선 5일장, 감자밭, 평창무이예술관 등 77개는 현재 Odii 검색 결과에서 관광지명과 지역이 검증되는 음원을 찾지 못해 404가 반환된다. 프론트는 이 경우 오디오 영역 전체를 숨기도록 되어 있어 재생 버튼이 보이지 않는 것이 정상 동작이다. 이는 플레이어 UI 오류가 아니라 원천 콘텐츠 매핑 부족이다.

## 응답 속도와 DB 캐시

성공 응답은 이미 `audio_guides` 테이블에 관광지·언어별로 저장된다. 첫 조회에서 Odii 검색 후 저장하고, 다음 조회부터는 외부 API를 호출하지 않는다. 운영 API에서 남이섬을 연속 조회했을 때 두 번째 요청이 약 44ms로 줄어드는 것을 확인했다.

현재 미제공 404는 DB에 부재 결과를 저장하지 않으므로 요청마다 Odii를 다시 조회한다. 정선 5일장 반복 요청은 약 294ms, 266ms로 측정됐다. 미제공 관광지를 자주 열어 보는 사용자가 많다면 `audio_unavailable_cache` 같은 TTL 기반 부재 캐시를 별도 이슈로 추가하면 외부 호출을 줄일 수 있다. 단, 부재 캐시는 Odii에 새 음원이 추가된 뒤에도 일정 기간 404를 유지할 수 있으므로 만료 시간이 필요하다.

## 재생 확인

- 기존 실기기 검증 캡처 `../issue-447/spot-2-audio-playing.png`에서 남이섬 음원이 00:04까지 재생됨을 확인했다.
- 최신 수정본의 오디오 단위·관광지 상세 테스트 22개가 모두 통과했다.
- 음원 파일 URL 4개를 직접 확인한 결과 모두 HTTP 200 `audio/mpeg`로 응답했다.

## 결론

현재 오디오 기능 자체와 성공 응답 캐시는 정상이다. 출시 전 별도 수정이 필요한 것은 77개 관광지의 Odii 콘텐츠 매핑이며, 이를 앱 코드로 임의 보정하면 다른 지역의 동명 관광지 음원을 잘못 연결할 위험이 있다. 부재 캐시는 성능 개선 항목으로는 유효하지만 필수 출시 차단 항목은 아니다.
