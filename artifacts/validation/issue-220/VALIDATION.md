# Issue #220 Validation

## 작업 요약

- 스탬프 투어 첫 진입 안내 카드의 높이와 내부 구성을 관광지 선택 후 표시되는 카드와 같은 계열로 맞췄다.
- 지도 우측 상단 수집률 배지를 탭 가능한 요소로 바꾸고, 시군별 스탬프 카드 화면으로 이동하도록 연결했다.
- 수집률 배지 이동 흐름을 위젯 테스트로 추가했다.
- 수집률 배지를 눌러 시군별 카드 화면으로 이동한 뒤 뒤로가기를 하면 기존 스탬프 투어 화면으로 돌아오도록 `push` 기반 이동으로 보정했다.
- 수집률 배지 터치 피드백에서 네모난 배경이 보이지 않도록 pill 형태의 시각만 유지했다.

## PAAR

### Problem

스탬프 투어 첫 진입 시 보이는 “여행할 지역을 골라보세요” 카드가 관광지 선택 후 카드보다 작고 단순해서 화면 전환 전후의 무게감이 달랐다. 또 우측 상단 수집률 배지는 스탬프 진행도를 보여주지만, 사용자가 더 자세한 시군별 스탬프 화면으로 이동할 수 있는 동선은 없었다.

### Action

안내 카드를 선택 카드와 동일한 42px 아이콘, 제목/상태 라벨, 설명, 하단 행동 영역 구조로 정리했다. 수집률 배지는 `InkWell`과 `Tooltip`을 적용해 터치 가능한 UI로 바꾸고, 탭 시 `/main/stamps/cities` 경로로 이동하도록 연결했다.

### Analysis

수집률 배지는 지도 안에 떠 있는 요소라 버튼처럼 과하게 보이면 지도를 가릴 수 있다. 그래서 기존 pill 형태는 유지하되 터치 피드백만 추가했다. 안내 카드는 실제 스탬프 찍기 버튼과 혼동되지 않도록 “지도에서 깃발 선택” 안내 영역으로 표현했다.

### Result

첫 진입 카드와 선택 카드의 시각적 밀도가 가까워졌고, 수집률을 누르면 마이페이지의 스탬프 투어 버튼과 같은 시군별 카드 화면으로 이동한다.
뒤로가기도 스탬프 투어 화면으로 자연스럽게 복귀한다.
