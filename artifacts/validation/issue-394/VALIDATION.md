## 확인 내용

- 선택 전 카드와 선택 후 카드가 같은 높이와 여백 체계 안에서 전환된다.
- 선택 후 카드에서 방문 인증 버튼이 유지된다.
- 기존 스탬프 화면 테스트에서 지도 선택, 상세 진입, 패스포트 이동, 보상 요청 흐름이 깨지지 않았다.
- 강원도 지도 크기와 중심은 유지하고, 배경에 인접 시도 윤곽만 옅은 초록 톤으로 추가했다.

## 트러블슈팅

### Problem

선택 후 카드에서 본문과 CTA가 기존 160px 콘텐츠 높이에 들어가지 않아 테스트 중 `Bottom overflowed by 7 pixels`가 발생했다.

### Action

선택 전/선택 후 콘텐츠 높이를 동일하게 168px로 조정하고, 공통 카드 최소 높이를 202px로 맞췄다.

### Analysis

선택 후 상태에는 지역 칩, 상태 칩, 장소명, 보조 설명, CTA가 모두 들어가므로 선택 전 안내 상태보다 정보량이 많다. 두 상태를 동일한 카드 컴포넌트에서 자연스럽게 보이게 하려면 선택 후 기준으로 안정 높이를 잡는 편이 안전했다.

### Result

스탬프 화면 테스트와 전체 Flutter 테스트에서 오버플로우 없이 통과했다.
