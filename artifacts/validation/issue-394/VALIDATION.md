# Issue 394 Validation

## 작업 범위

- 스탬프 메인 지도에 한반도 육지 배경 레이어를 추가했다.
- 남한 인접 시도와 북한 polygon을 각각 따로 보여주던 방식을 정리해, 한반도 landmass를 하나의 비인터랙티브 배경처럼 렌더링했다.
- 스탬프 메인 하단 카드를 선택 전/선택 후 공통 컨테이너 기반 UI로 정리했다.
- 선택 카드에서 `원주 · 방문 인증 대기`, `이 명소에서 인증하면 ... 스탬프를 받을 수 있어요` 안내 문구를 제거했다.
- 기존 스탬프 지도, 마커 선택, 패스포트 이동, 방문 인증 진입 흐름은 유지했다.

## 확인 내용

- 선택 전 카드와 선택 후 카드가 같은 높이와 여백 체계 안에서 전환된다.
- 선택 후 카드에서 방문 인증 버튼이 유지된다.
- 기존 스탬프 화면 테스트에서 지도 선택, 상세 진입, 패스포트 이동, 보상 요청 흐름이 깨지지 않았다.
- 강원도 지도 크기와 중심은 유지하고, 배경에 한반도 북부/남부 landmass를 옅은 초록 톤으로 추가했다.
- 테스트 렌더링 중 디버그 로그로 `Stamp context GeoJSON regions: 한반도 북부, 한반도 남부`가 출력됨을 확인했다.
- 선택 카드에서 지역/인증 대기 문구와 설명 문구가 더 이상 노출되지 않음을 테스트 기대값으로 확인했다.

## 트러블슈팅

### Problem

선택 후 카드에서 본문과 CTA가 기존 160px 콘텐츠 높이에 들어가지 않아 테스트 중 `Bottom overflowed by 7 pixels`가 발생했다.

### Action

선택 전/선택 후 콘텐츠 높이를 동일하게 168px로 조정하고, 공통 카드 최소 높이를 202px로 맞췄다.

### Analysis

선택 후 상태에는 지역 칩, 상태 칩, 장소명, 보조 설명, CTA가 모두 들어가므로 선택 전 안내 상태보다 정보량이 많다. 두 상태를 동일한 카드 컴포넌트에서 자연스럽게 보이게 하려면 선택 후 기준으로 안정 높이를 잡는 편이 안전했다.

### Result

스탬프 화면 테스트와 전체 Flutter 테스트에서 오버플로우 없이 통과했다.

### Problem

강원도 서쪽/남쪽에는 배경 지형이 일부 보였지만, 북쪽은 파란 배경만 남아 지도가 잘린 것처럼 보였다.

### Action

사용자 제공 `TL_SCCO_CTPRVN.json`의 feature 이름을 확인했고, 남한 시도 데이터에는 `강원도`, `경기도`, `충청북도`, `경상북도` 등만 있으며 북쪽 지형을 채울 북한 polygon이 없음을 확인했다. 따라서 Natural Earth의 `ne_10m_admin_0_countries`에서 북한 외곽 feature만 추출해 기존 Korea 2000 투영/정규화 방식으로 변환했다.

### Analysis

이번 지도는 전국 fit이 아니라 강원도 확대 뷰가 목적이다. 그래서 강원도 bbox 기준 렌더링은 유지하고, 북한/경기/충북/경북 polygon 전체를 먼저 그린 뒤 카드 viewport가 자연스럽게 clip하도록 했다. GeoJSON 자체를 화면 크기에 맞춰 미리 잘라내면 필요한 지형 일부가 사라질 수 있어, 렌더 모델은 전체 selected feature를 유지한다.

### Result

초기 보완 단계에서는 `gangwon_context_region_test`로 북한, 경기, 충북, 경북이 각각 강원도 북쪽/서쪽/남쪽 방향에 배치됨을 검증했다. 이후 사용자 피드백에 따라 시도별 조각 표현을 제거하고, 한반도 landmass 단일 배경으로 재정리했다.

### Problem

시도별 polygon과 북한 polygon을 각각 채우고 외곽선을 그리자, 배경이 하나의 지형이 아니라 여러 행정구역 조각처럼 보였다. 특히 강원도 왼쪽과 북쪽에서 경계선이 눈에 띄어 사용자가 지도가 잘린 것처럼 느낄 수 있었다.

### Action

배경 GeoJSON을 Natural Earth의 남/북 한반도 landmass로 재생성하고, Flutter 렌더링에서는 모든 배경 polygon을 하나의 `Path`로 합쳐 fill만 그리도록 변경했다. 배경 행정 경계선은 제거하고, 강원도 흰색 강조와 강원도 시군 경계만 전면 레이어에 유지했다.

### Analysis

스탬프 화면의 목적은 행정구역 정보 제공이 아니라 강원도가 한반도 안에 자연스럽게 연결되어 있다는 맥락을 보여주는 것이다. 따라서 주변 지역은 클릭 불가능한 연속 육지 배경으로 처리하고, 정보 계층은 `한반도 배경 → 강원도 강조 → 강원도 시군 경계 → 마커` 순서로 단순화하는 편이 맞다.

### Result

`gangwon_context_region_test`가 한반도 북부/남부 landmass가 강원도 북쪽, 서쪽, 남쪽으로 충분히 확장되는지 검증한다. `stamp_book_screen_test`에서도 기존 스탬프 선택, 패스포트 이동, 방문 인증 진입 흐름이 유지됐다.
