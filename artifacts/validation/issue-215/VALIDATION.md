# Issue #215 검증 기록

## 작업 목표

- 감자 도감에서 `대표 감자 변경` 버튼은 대표 감자를 고르는 흐름만 담당하게 분리한다.
- 대표 감자의 상세 설명, 획득 방법, 희귀도, 성장 정보는 별도 `정보 보기` 흐름으로 확인하게 한다.
- 대표 감자 변경 시트 안에서도 감자별 상세 정보를 확인할 수 있게 하되, 상세 조회가 대표 감자 변경으로 오인되지 않게 한다.
- 앱 완전 종료 후 재실행 시 `onboading.png`가 바로 지나가지 않고 사용자의 터치를 기다리게 한다.
- 지도 감자 스팟 핀, 마이페이지 기본 프로필, 감자 도감 메인, footer 여백을 같은 앱 톤으로 정리한다.

## PAAR

### Problem

감자 도감 메인에서 대표 감자 변경 흐름과 감자 상세 정보 확인 흐름이 섞여 보일 가능성이 있었다. 사용자는 `대표 감자 변경`을 누르면 나의 도감이 열리길 기대하지만, 감자 상세 정보까지 같은 동작에 섞이면 대표 변경과 감자 탐색의 목적이 흐려질 수 있다.

### Action

- 대표 감자 카드에 `정보 보기` 보조 버튼을 추가했다.
- `대표 감자 변경` 버튼은 나의 감자 도감 선택 시트만 열도록 유지했다.
- 나의 감자 도감 선택 시트 안의 각 감자 카드에 `상세` 버튼을 추가했다.
- 상세 시트에는 감자 소개, 획득 방법, 희귀도, 지역, 성장 진행 정보를 표시했다.
- 상세 시트에는 `대표 감자로 설정` 같은 변경성 CTA를 넣지 않아 읽기 흐름과 변경 흐름을 분리했다.
- `SessionStartupScreen`을 자동 라우팅 화면에서 터치 게이트 화면으로 바꿔 `onboading.png`와 `터치하여 시작하기`가 항상 먼저 보이게 했다.
- Web/iOS/Android 지도 핀을 직접 그린 감자 캐릭터형 핀에서 감자 이모지를 담은 둥근 핀 형태로 정리했다.
- 마이페이지는 사용자 이름과 기본 프로필 중심의 헤더를 추가하고, 기본 프로필은 감자 이모지 대신 앱 톤의 사람 아이콘으로 표시했다.
- 감자 도감 메인은 레퍼런스의 큰 대표 감자 구성을 참고하되 배경 장식, 감자 이모지, 물음표 이모지는 추가하지 않았다.
- 감자걸음은 레퍼런스 톤을 유지하되 `PotatoGrowthSummary`의 `todaySteps`, `dailyStepGoal`, `stepRatio` 값을 다시 표시하도록 조정했다.
- footer 내부 top padding을 늘려 아이콘과 라벨이 위로 붙어 보이지 않게 조정했다.

### Analysis

대표 감자 변경은 사용자의 현재 상태를 바꾸는 행동이고, 감자 상세 조회는 정보를 확인하는 행동이다. 두 행동을 같은 버튼이나 같은 카드 탭에 섞으면 실수로 대표 감자를 바꾸거나, 반대로 상세 정보를 어디서 확인해야 하는지 찾기 어려워질 수 있다. 따라서 메인 카드에서는 `정보 보기`와 `대표 감자 변경`을 나란히 두고, 선택 시트에서는 카드 탭은 대표 변경, 작은 `상세` 버튼은 정보 조회로 역할을 나눴다.

### Result

- 대표 감자 카드에서 현재 대표 감자의 상세 정보를 바로 확인할 수 있다.
- 대표 감자 변경 시트에서 상세 버튼을 눌러도 대표 감자가 바뀌지 않는다.
- 감자 도감 메인 화면은 여전히 오늘 걸음 수와 대표 감자 중심으로 단순하게 유지되며, #209 HealthKit 백그라운드 동기화 결과가 summary provider를 통해 화면에 반영될 수 있다.
- 앱 시작 시 사용자가 터치하기 전에는 세션 복구/로그인 화면으로 자동 이동하지 않는다.
- 지도 핀은 감자 정체성을 유지하되 기존보다 장식적인 요소를 줄였다.
- 삭제된 감자도감 디자인 레퍼런스 이미지는 복원하지 않았다.

## 남은 리스크

- 실제 iOS/Android 화면 높이에서 대표 카드의 두 버튼이 너무 좁아 보이는지는 실기기 캡처 QA가 필요하다.
- 감자 이미지가 최종 에셋으로 교체되면 상세 시트의 이미지 크기와 여백을 다시 확인해야 한다.
- iOS/Android 네이티브 지도 핀은 코드상 디자인을 맞췄지만, 실제 SDK 렌더링은 실기기 화면 캡처로 한 번 더 확인해야 한다.
