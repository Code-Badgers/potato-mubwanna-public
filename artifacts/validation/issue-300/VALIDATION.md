# Issue #300 검증 기록

## 목표

- 지도에 표시되는 감자 마커가 실기기에서 작아 보이는 문제를 완화한다.
- 출시 전 심사에 걸릴 수 있는 미완성 고객센터 메뉴 연결을 제거한다.
- 공지사항 메뉴는 유지하되, 빈 화면이 아니라 기본 안내 내용을 제공한다.

## 진행 내용

### 1. 감자 지도 마커 크기 확대

- iOS 네이티브 카카오 지도 마커 크기를 약 1.5배 확대했다.
- Android 네이티브 카카오 지도 마커 비트맵 크기를 확대했다.
- Web 카카오 지도 마커 DOM 크기와 내부 감자 아이콘 크기를 함께 확대했다.

고민한 점:

- 마커가 너무 커지면 지도 위 장소 밀도가 높은 구역에서 답답해질 수 있다.
- 다만 사용자가 실제 휴대폰에서 작다고 느낀 문제가 먼저였기 때문에, 기본 크기를 키우되 Web은 지도 확대 배율에 따라 최대 스케일을 제한했다.

해결:

- 플랫폼별 마커 크기만 조정하고, 지도 데이터 및 선택 로직은 건드리지 않았다.

### 2. 미완성 고객센터 메뉴 제거

- 마이페이지 계정 메뉴에서 `고객센터` 항목을 제거했다.
- 연결되지 않은 기능을 출시 화면에서 숨겨 심사와 사용자 혼란 리스크를 줄였다.

고민한 점:

- 고객센터는 실제 운영 시 필요하지만, 현재는 연결 화면과 문의 흐름이 준비되지 않았다.
- 빈 메뉴로 남겨두는 것보다 이번 출시 범위에서는 제거하는 편이 더 안전하다.

해결:

- 메뉴 목록에서 고객센터를 제거하고, 위젯 테스트에서도 고객센터가 보이지 않음을 검증했다.

### 3. 공지사항 화면 연결

- `/notices` 라우트를 추가했다.
- 마이페이지의 `공지사항` 메뉴를 공지사항 화면으로 연결했다.
- 감자 스팟, 방문 인증, 보상 운영에 대한 기본 안내 카드 3개를 제공했다.

고민한 점:

- 운영 공지 API가 없는 상태에서 빈 공지 목록을 보여주면 미완성처럼 보일 수 있다.
- 반대로 너무 많은 정책성 문구를 넣으면 앱 첫인상이 무거워질 수 있다.

해결:

- 지금 앱 사용에 필요한 안내만 짧은 카드 3개로 정리했다.
- 추후 운영 공지 API가 생기면 정적 카드 대신 서버 데이터를 연결하면 된다.
