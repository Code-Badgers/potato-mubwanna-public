# Potato Mubwanna Frontend

Flutter mobile app for the Potato Mubwanna location-based stamp rally service.

## Stack

- Flutter 3.x
- Dart
- Riverpod
- GoRouter
- Dio
- Kakao Map
- Firebase Cloud Messaging
- Flutter Secure Storage

## Structure

```txt
lib/
  app/
  core/
  features/
  shared/
```

## Commands

```bash
flutter pub get
flutter analyze
flutter test
```
